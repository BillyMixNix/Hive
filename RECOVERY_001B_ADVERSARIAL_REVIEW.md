# Independent adversarial review — findings before repair

An independent read-only subagent reviewed the closure after the initial deterministic gate. These findings were recorded **before** follow-up changes. The synthetic Gradle exploit and its fail-closed scope policy are separately documented in `RECOVERY_GRADLE_TRUST_AUDIT.md`.

1. **High — protected-test diagnostic transport (source-backed reachable path; model exfiltration not executed).** `hive_jvm.copy_external_verification_input` writes host-frozen JUnit source into the verifier project. Candidate Java can read files in that project. `jvm_runner._reports` copies emitted failure messages into `failure_diagnostics`, and `hive._targeted_diagnostic` includes those strings in a later worker correction prompt. The reviewer used a model-free synthetic sentinel in a verifier-shaped result and observed the sentinel in the correction diagnostic. No actual Java exfiltration or model call was run. This defeats an unconditional claim that protected test bytes can never reach model-visible feedback. A correction-transport guard or explicit fail-closed policy is required before a live replay can claim that invariant.

2. **Medium — fixture resolver target identity (code-level, not observed corpus mutation).** The initial resolver checked that the target was separate from its current repository but did not prove that it was a registered disposable Git worktree. A caller could point it at a different checkout or corpus directory. An original Windows junction might also be obscured by `resolve()` before link checks. The resolver should require a detached linked worktree with the same Git common directory and historical corpus identity, and check the raw root for links/junctions before resolving.

3. **Medium — Gradle guard qualification boundary (code-level).** The Java-only restriction applies to the recovered NeoForm Runtime profile. Known Gradle authority filenames are rejected for all profiles, but arbitrary other Gradle profiles are not generally qualified against indirect build-control inputs. The bounded frozen M3.2 profile remains guarded. Reports must not claim general Gradle safety.

4. **Medium — image tag versus image ID (source-backed mismatch, no substitution performed).** The environment script initially checked that the frozen Docker image ID existed locally, whereas `hive_verifier.run_isolated` invokes a mutable default image tag. The host could have the right ID present while the tag points elsewhere. The environment check must bind the actual invoked tag to the frozen ID before reporting PASS. An ID-based launch would remove the remaining tag race, but would require a separately justified verifier change.

The review also examined candidate/baseline confusion, evidence mutation, reviewer override, hidden apply, stale-base behavior, and provenance drift. No additional concrete bypass has yet been reported; promotion remains unavailable and no apply path was exercised. Any later finding will be appended without erasing these observations.

## Disposition after findings were recorded

- Finding 1: RC1 candidate adapter now blocks every targeted-verification correction and semantic reviewer model call whenever host-frozen tests are present. The recovered controller remains byte-preserved. This is an explicit fail-closed availability tradeoff, not a claim that arbitrary emitted text has been safely sanitized. The run retains deterministic verifier evidence; the model cannot receive those post-verification prompts. Deterministic tests exercise blocked correction/reviewer calls and the normal no-frozen-test path. Qualification of useful, leakage-resistant diagnostics remains future work.
- Finding 2: Resolver now requires a detached linked worktree with the same Git common directory, exact historical corpus tree and exact committed requesting-test hashes. It checks root symlinks/junctions before resolution; unmapped and substituted destinations remain rejected. A new test rejects an arbitrary separate directory. The clean-checkout fixture worktree is registered and detached.
- Finding 3: All recognized Gradle profiles now receive source-only `src/main/java/**/*.java` scope; nested control basenames and directories are rejected even without a profile. The RC1 frozen-test isolation probe was adapted to use an authorized Java fixture while preserving its hidden-context assertion. The archived historical tests were not changed.
- Finding 4: Environment verification now checks both exact image ID existence and resolution of the *actual invoked* `DEFAULT_IMAGE` tag to that same ID. A regression test rejects a simulated mismatched tag. This does not eliminate the race between preflight and launch; no tag mutation was observed. The bounded replay must repeat the image binding check immediately before verification.
- Finding 5: remains a documented reproducibility limitation, not repaired here. The exact image/cache cannot yet be independently reacquired from the repository alone.
