# Hive Failure Modes

This document is a threat model for claims, not merely code. A mechanism that “works” by moving complexity, reading hidden evidence, weakening criteria, or relying on human semantics has failed the relevant Hive hypothesis even if its output is correct.

## Severity policy

- **P0**: invalidates the experiment or the claimed mechanism.
- **P1**: creates a material confound; no positive interpretation until controlled.
- **P2**: limits scope, robustness, or measurement precision and must be disclosed.

## Authority and state failures

| Failure | Severity | Detection | Required response |
|---|---:|---|---|
| Plan/prediction/proposal materializes its projected effect | P0 | Planned transfer followed past proposed date | Reject promotion; record intention separately |
| Confidence promotes unsupported state | P0 | High-confidence false/predicted claim | Confidence never grants authority |
| Mutable state diverges from event replay | P0 | Recompute snapshot/hash from ledger | Fail closed; canonical state is replay-only |
| Record time confused with effective time | P0 | Backdated late evidence and as-known-then query | Require bitemporal cutoffs |
| Same-time conflict resolved by input order or ID | P0 | Permute event order and IDs | Produce explicit disputed/unknown state |
| Superseded fact erased | P1 | Query before/after validity boundary | Preserve historical interval and source |
| False, unknown, disputed, and historical collapse | P0 | Collision/round-trip tests | Use orthogonal basis/truth/temporal axes |
| Cyclic inference self-authorizes | P0 | A depends on B and B on A | Reject cycle; require named acyclic rule lineage |
| Partial event application | P0 | One precondition fails in multi-effect event | Reject all effects atomically |
| Counterfactual mutates canonical ledger | P0 | Compare ledger/state hash before and after | Keep branch noncanonical and ephemeral |
| Policy version retroactively changes old decisions | P1 | Replay old head under recorded policy | Decision records bind policy version |

## Compression and decompression failures

| Failure | Severity | Detection | Required response |
|---|---:|---|---|
| Packet shrinks by silently dereferencing the full raw ledger | P0 | Remove undeclared store; log every dependency access | Declare as retrieval or count all dependency bytes |
| Schema/ontology/codebook carries the information | P0 | Cold-start and amortized effective-cost accounting | Report packet and effective cost separately |
| IDs/order encode answers | P0 | Normalize IDs/order; rotate labels/tasks | Count bytes and reject task-specific steganography |
| Preserve/discard contract omits modeled distinctions | P0 | Coverage validation | Mark unmodeled distinctions explicitly unknown |
| Missing dependency is guessed | P0 | Remove a required component | Return incomplete/unknown, never hallucinate |
| Reconstruction atom has no ultimate source | P0 | Lineage traversal and hash verification | Reject atom/result |
| Current state round-trip loses plan/authority distinction | P0 | Near-pair histories differing only in status | Mark harmful lossy compression |
| Collision joins task-distinct histories | P0 | Search `E(H1)=E(H2)` with differing oracle result | Falsify sufficiency in that scope |
| Random-byte deletion masquerades as frontier | P1 | Inspect removal manifest | Ablate semantic components only |
| Oracle relevance labels choose the packet | P0 | Audit compressor inputs | Candidates must be query/heldout blind |
| Singleton ablation called “minimum” | P1 | Check evaluated subsets/interactions | Label exact vs one-minimal approximation |
| Redundancy removed at the cost of robustness/transfer | P1 | Stress and heldout tests | Keep quality dimensions on Pareto frontier |
| Full-history reconstruction hides selective failure | P1 | Measure unnecessary atoms/bytes | Require task-conditioned selection metrics |

## False causality

Current replay encodes prerequisites and temporal transitions. It is not automatically a structural causal model.

| Failure | Severity | Detection | Required response |
|---|---:|---|---|
| Temporal adjacency treated as causal edge | P0 for causal claim | A precedes B with no mechanism | Answer unsupported/insufficient |
| Preconditions relabeled causes | P1 | Observationally equivalent worlds with different intervention outcomes | Narrow claim to transition dependency |
| Confounding omitted | P1 | Hidden common-cause synthetic worlds | Use an explicit causal oracle or do not score causal counterfactuals |
| Counterfactual generated by deleting history only | P1 | Compare to intervention semantics | Label as replay counterfactual, not `do()` causality |

Typed edges must distinguish `CAUSE`, `PRECONDITION`, `EVIDENCE`, `SUPERSEDES`, `CONTAINS`, and `TEMPORAL_BEFORE`.

## Solver and experimental failures

| Failure | Severity | Detection | Required response |
|---|---:|---|---|
| Raw is near chance | P0 for representation comparison | Preregistered Raw gate | Report solver-incapable; no winner |
| Solver chosen after condition results | P0 | Protocol/source audit | Freeze solver panel before output |
| Calls, context, tools, or retries differ | P0 | Physical call artifacts and config comparison | Invalidate run |
| Interface failure erases semantic answers | P1/P0 by protocol | Separate parser/admissibility from correctness | Constrain output; preserve raw result; follow frozen rule |
| Truncation/timeout salvaged | P0 | Completion/token metadata | Fail closed, no repair in run |
| Automatic judges disagree | P1 | Independent oracle outputs | Expose disagreement; mark invalid/inconclusive as preregistered |
| Outcome-derived error relabeled independent reasoning evidence | P1 | Trace metric provenance | Label diagnosis as outcome-derived |
| Fixed batch/template pseudoreplicated as many independent cases | P1 | Generator/batch hierarchy | Report effective replication unit |

## Representation-learning failures

| Failure | Severity | Detection | Required response |
|---|---:|---|---|
| LLM summary called learned abstraction | P0 for learning claim | Check origin, heldout transfer, bidirectionality | Keep status `model_proposed` |
| Candidate sees heldout question/answer/oracle refs | P0 | Input hash/canary/blindness audit | Invalidate candidate and run |
| Task-specific names leak answer structure | P0 | Rename/permute symbols and labels | Use opaque identifiers and query-blind language |
| Same generator split called transfer | P1 | Hold out generator/mechanism/vocabulary | Label interpolation only |
| Answer table passes as representation | P0 | Surprise queries and task rotation | Restrict candidate language and query access |
| Human ontology grows while packet shrinks | P0 | Human-origin ledger and ontology bytes | Attribute gain to engineering, not learning |
| More candidates/compute create apparent learning | P1 | Matched search budget | Compare at equal total resources |
| Candidate copies raw history losslessly | P1 | Description length/effective cost | Compare to lossless/minified serialization controls |

## Failure attribution and repair failures

| Failure | Severity | Detection | Required response |
|---|---:|---|---|
| Solver error blamed on representation | P0 | Controlled layer-specific fault injections | Block repair attribution |
| Repair receives oracle-identified missing atom | P1 | Audit proposal inputs | Call it deterministic repair plumbing, not self-diagnosis |
| Repair fixes observed case but forgets locked cases | P0 | Protected old/new/counterexample suite | Reject promotion |
| Candidate mutates in place | P0 | Version/content hash audit | Immutable new version only |
| Rollback deletes evidence or cannot reproduce old behavior | P0 | Exact active hash/outcome replay | Block promotion until rollback passes |
| Candidate changes evaluator or threshold | P0 | Protected-file/protocol hash | Invalidate |
| Migration changes semantics of old component IDs | P0 | Versioned schema and compatibility tests | Preserve old decoder and refs |

## Meta-learning and recursive-improvement failures

| Failure | Severity | Detection | Required response |
|---|---:|---|---|
| Library accumulation called recursive improvement | P0 | Frozen proposer with same library control | Attribute to memory/library only |
| More compute/calls called intelligence gain | P0 | Matched total-resource ledger | Invalidate recursive attribution |
| Benchmark/evaluator changes between generations | P0 | Protocol hashes | Invalidate cycle |
| Difficult cases disappear | P0 | Fixed and future heldout manifests | Invalidate cycle |
| Success criteria move | P0 | Signed preregistration/registry | Preserve negative result |
| Meta-profile merely contains answers | P0 | Shuffled/no-meta and canary tests | Reject profile |
| Improvement is overfit to past families | P0 | Nested future meta-heldout episodes | Reject recursive claim |
| Human corrections increase each generation | P0 | Human interventions/bytes | Attribute improvement to humans |
| Proposed machinery self-evaluates | P0 | Independent protected evaluator | Reject evidence |
| Apparent slope lacks replications | P1 | Multiple generators/seeds/episodes | Keep result exploratory |

## Apparatus and evidence failures

- broken source/artifact hashes;
- missing raw inputs or outputs;
- incomplete physical attempt records;
- resume that changes prior evidence;
- untracked protocol-critical source;
- evaluator or case mutation;
- missing failure artifact;
- evidence-level update from an invalid run;
- candidate allowed to write the claim registry;
- result reported without its scope and capability gate.

Any of these invalidates an empirical evidence upgrade.

## Demo interpretation guard

The deterministic whole-system demonstration intentionally begins with already typed observations/events, uses a handcrafted codec, deletes a known component, and invokes a deterministic missing-dependency proposer. It may establish:

- interfaces connect;
- authority and provenance invariants hold;
- a lossy representation failure is detected;
- a new immutable candidate is proposed and evaluated;
- promotion and rollback work.

It may not establish:

- natural-language canonicalization;
- causal discovery;
- learned compression;
- learned abstraction;
- autonomous failure localization;
- transfer;
- recursive improvement.

## Decisive thesis falsifiers

1. The engineered codec loses its apparent benefit against minified/dictionary-coded canonical serialization.
2. Representation discovery cannot operate without human event/authority/causal labels.
3. Learned representations fail surprise queries that Raw-capable solvers answer.
4. Claimed causal representations cannot distinguish observationally equivalent intervention worlds.
5. Learned candidates fail generator-, vocabulary-, structure-, or domain-heldout transfer.
6. Representation repair cannot localize controlled faults or avoid locked regressions.
7. Full effective cost removes the apparent compression frontier.
8. Meta-representation treatment does not beat frozen/shuffled/no-meta controls on future episodes at matched compute.

Repeated, preregistered negative results on the last item falsify the scoped strongest Hive thesis. Broad existential wording must not be used as an escape hatch.
