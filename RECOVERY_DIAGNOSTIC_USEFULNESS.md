# Model-free usefulness replay

The structured envelope distinguishes the frozen J001 baseline from a timeout without revealing `truncationNeverSplitsAPair`, assertion text or protected source. Conversion of the preserved 001B baseline verifier record yields `FAILED / FROZEN_ACCEPTANCE_FAILED`, host expected 3 cases, compilation UNKNOWN. The raw audit record reports 3 cases and 1 failure, but those candidate-influenced numbers do **not** reach a model. The original host task and owned source remain separately available.

| Historical/controller condition | Safe, host-owned signal | What is intentionally withheld |
| --- | --- | --- |
| Planner/schema failure | Existing planner validator feedback, before frozen verifier | No JUnit evidence exists |
| Worker/provider failure | Existing distinct local-runtime classification | Provider exception free text is not verifier diagnostic |
| Edit preflight failure | Existing scoped edit validator | No protected verifier result exists |
| Frozen acceptance failure | `FROZEN_ACCEPTANCE_FAILED`, fixed check result, host-frozen expected case count | Reported XML counts, test/class names, assertions, stack trace, logs |
| Ownership/scope violation | Existing host validator and exact authorized scope | Candidate-written diagnostic strings |
| Timeout | `TIMED_OUT` when host check detail records a strict timeout boolean | Last Gradle output and trace text |
| Full-gate regression | `FULL / FAILED`, known fixed check ID or generic `VERIFIER_FAILED` | Full-suite test names/messages |
| Deterministic PASS | `FULL / PASSED`; original verifier remains authority | No extra semantic claim |
| Reviewer unavailable | Existing `review_disposition=unavailable`, separate from verification | Provider failure text not shown as verifier fact |
| Promotion unavailable | Recovery `promotion_authorization=unavailable` | No apply path |

The projection cannot reliably diagnose which hidden case failed, how many candidate-reported cases failed, why an assertion failed, or whether `compileJava` truly entered. This reduces correction specificity by design. Future richer diagnostics require a separately proven host-owned signal, never copying arbitrary output. Model-free tests cover synthetic sentinel exfiltration, malformed results, exact would-be correction/reviewer requests, prompt telemetry, and preservation of verifier FAIL despite a changed diagnostic object.
