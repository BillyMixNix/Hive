# HIVE-FACTORIAL-003 preregistered execution policy

The primary experiment is 16 repaired Hive trials: four exact FACTORIAL-002 tasks, two identical-digest local models, two replicates. The historical seeded order is filtered to its Hive cells without changing their relative order. There is no new single-agent condition because the historical adapter invokes Hive; importing its repaired implementation would contaminate that control.

The controller is a byte-identical isolated copy of the completed HIVE-REVIEWER-POLICY-001 source. No production changes, task-specific adjustments, replacements, manual hints, or candidate promotion are allowed. Model inputs consist only of the current frozen task, fresh baseline, normal controller context and normal verification feedback. Hidden tests remain host-only; previous solutions and other trials never enter model context.

Role output caps match both FACTORIAL-002 and the final production app: planner 2048, workers 6000, reviewer 1536. The earlier runtime replacement's experiment-specific all-role 2048 override is not the production configuration and is not inherited. Context is 12288, temperature 0.1, truncation disabled. Provider retry remains at most two HTTP attempts under its existing predicate, each with the unchanged 900-second generation ceiling. The historical 250000 conservative aggregate token reservation and 3600-second model-decision wall ceiling are preserved. Normal controller correction/observation budgets are frozen. No new trial follows from any failed trial as a replacement.

There is one non-task readiness request per model before all task trials, under planner configuration. No additional warmups occur. Actual model residency, automatic Ollama expiration and Resource Saver behavior are observed, not controlled. No parameter, process, memory or residency intervention is made in response to outcomes. Trials execute serially in frozen order.

The existing NFRT attestation authorizes dependency reuse only when source differences are confined to SnapshotFormatter.java. This pre-study limitation can block other task candidates at verifier compatibility validation. The attestation and fail-closed production policy are retained exactly. Expanding them would be a new repair and is excluded from this study. Such failures are reported as infrastructure/policy failures, separately from model correctness.

Verified software success requires a model-produced scoped edit, frozen acceptance PASS, full gate PASS, no independent controller blocker, and matching verified stage identity. Semantic review is separate and cannot erase that deterministic result. External-root candidates retain their native non-promotable state. Study-level human promotion authorization is always `not_authorized`; the controller's separate `blocked` policy state is retained verbatim.

The primary comparison is historical Hive 0/16 versus repaired Hive X/16. Report a two-sided 95% Clopper–Pearson exact binomial interval and two-sided Fisher exact test, with absolute success-rate difference. These are descriptive comparisons across time and multiple intentional repairs, not attribution to an individual repair. Subgroup counts and transition, runtime and cost measures are reported without treating earlier failure as efficiency. Incomplete runs retain their observed denominator and are never padded with inferred outcomes.

Instrumentation captures exact outgoing request bytes and incoming streaming bytes without altering model content. It copies transient candidate edits before the unchanged verifier and retains verifier return values or exceptions. Resource sampling is asynchronous, approximately every 30 seconds and at call boundaries, plus synchronous trial-boundary observations. This overhead and automatic model swapping are runtime limitations of the measured environment.

Stop only at all 16 completed trials, integrity compromise, unrecoverable environment failure, or explicit user instruction. No unattended apply/promotion is performed. All historical evidence is immutable and rehashed after the study.
