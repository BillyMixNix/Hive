# Host-bound RECOVERY-002 replay contract

The machine contract is `recovery/rc1-replay/REPLAY_ENVIRONMENT_CONTRACT.json`; `verify_replay.py` is the pre-model gate. It requires an explicit exact 001C commit and clean checkout on the recovery branch, unchanged historical corpus and frozen M3.2 baseline, exact J001 request/test hash, protected test absent from model-visible baseline, source-only Java write scope, frozen Gradle profile, and the 001B environment manifest. It calls the 001B verifier environment checker, which hashes **all 4,866** selected files, verifies provenance/NFRT attestation, and checks Docker tag-to-image-ID binding. It independently rejects every extra/missing cache-root file or link, including a Gradle init script outside the sealed inventory. It also verifies the host Python executable, runtime DLL, stdlib/DLL trees, installed package files, exact import-path tail, startup hooks and startup environment against a sealed 001C Python manifest. The entry import path must be inside the clean replay checkout; user-site imports fail closed. Missing, extra, altered or unavailable artifacts abort; no mutable fallback is permitted. The existing 240-second targeted deadline, offline Gradle policy and frozen tests remain unchanged.

The future `hive_canonical.replay.run_host_bound_j001` entrypoint calls this gate **before** invoking any supplied model callable. It atomically creates a persistent claim file in the isolated run root; a second sequential or restarted attempt using that root fails before a model call, even if the first attempt fails. RECOVERY-002 must preassign one immutable run root and may not choose a new root as an unauthorized replacement. It then pins the copied verifier's image reference to the verified immutable image ID for actual `docker run`, closing the inspect-tag/run-tag race. It sets only the sealed cache and NFRT environment locations for the bounded run and restores process state afterward. A process lock prevents concurrent replay entrypoints; RECOVERY-002 must run in a dedicated process with no other verifier jobs. Candidate isolation and source integrity remain the canonical controller's responsibility. No promotion method exists; `promotion_authorization=unavailable`.

Eligibility is exactly one frozen J001 replay, the recovered RC1/001C controller, exact attested host environment, exact frozen baseline/acceptance, `src/main/java/**/*.java` authorization with J001's exact file scope, no build-control writes, safe structured diagnostics only, no raw verifier diagnostic to any model, no promotion/apply/production mutation, no automatic expansion, and complete preservation of requests, responses, edits and verifier artifacts. The run stops after that single replay and is reported; 001C makes **zero** such calls.

A successful run under this contract demonstrates recovery on the **attested recovered host**. It does not demonstrate clean-machine reproducibility. If the exact 001C commit, source/provenance manifest, image, one cache hash, baseline, frozen test, or safe diagnostic boundary differs, HIVE-RECOVERY-002 must stop before a model request. Historical `run.json`/chat-context import and resume from raw verifier audit records are not in this replay envelope.
